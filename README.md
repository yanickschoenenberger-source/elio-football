# ELIO FOOTBALL — Penalty Arena

A browser-based football penalty game with a darker, more realistic stadium presentation, club/national-team selection, and curated player selections.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example `elio-football`).
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub Pages will publish the game at `https://YOUR-USERNAME.github.io/elio-football/`.

## Notes
- No build tools, server, or external libraries required.
- Responsive for desktop, tablet, and mobile.
- Player lists are curated examples, not a live data feed. For fully up-to-date squads, connect a football data API and refresh the data regularly.
